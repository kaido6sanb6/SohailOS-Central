# SohailOS Knowledge Graph Schema

## Core entities

Person, Organization, Place, Event, Work, Book, Paper, Film, Theory, Method, Dataset, Repository, Model, Software, HistoricalPeriod, Ideology, Institution, Variable, ResearchQuestion, Claim, Evidence, Citation, Source, Capability.

## Core relations

IS_A, PART_OF, RELATED_TO, INFLUENCES, CONTRADICTS, SUPPORTS, CITES, AUTHORED_BY, LOCATED_IN, OCCURRED_IN, DEPENDS_ON, IMPLEMENTS, FORK_OF, SUCCESSOR_OF, DERIVED_FROM, EVALUATED_BY, SUPPORTED_BY, PRODUCES, RETRIEVES, ANNOTATES.

## Provenance

Claims and extracted knowledge retain source, path/identifier, commit or revision, content hash where available, retrieval timestamp, transformation chain, license status, trust tier, evidence class, confidence/uncertainty, and permalink/DOI/URI.

## Evidence classes

PRIMARY_CODE, OFFICIAL_DOCUMENTATION, OFFICIAL_PROJECT, MODEL_OR_DATASET_CARD, PEER_REVIEWED_PAPER, OFFICIAL_BENCHMARK, ISSUE_OR_PR, SECONDARY_SOURCE, SEARCH_SNIPPET.

Search snippets are discovery aids, not final authority.
