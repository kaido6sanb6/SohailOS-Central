# SohailOS Workflows

## Research
Question → concepts → competing explanations → literature → theory → hypotheses → design → data → analysis → interpretation → limitations → publication.

## SPSS/R
Research question → hypotheses → variable audit → measurement → data quality → cleaning → reliability/validity → descriptives → assumptions → analysis → effect sizes/confidence intervals → diagnostics → interpretation → reporting.

## Product
Idea → problem → target user → unmet need → alternatives → value proposition → constraints → MVP → user flow → PRD → architecture → data model → prototype → implementation → testing → launch → measurement → iteration.

## AI
Problem → determine AI suitability → select capability/model → prototype → evaluation → cost/latency/privacy analysis → reliability checks → deployment → monitoring.

## Automation
Trigger → input → validation → transformation → decision → output → logging → exception handling.

## Decision
Objective → constraints → options → evidence → risks → reversibility → opportunity cost → decision → review date.

## Learning
Goal → baseline → prerequisites → curriculum → practice → project → assessment → next level.

## Critical analysis
Reconstruct strongest version → identify assumptions → contradictions → strongest support → strongest opposition → evidence that would change the conclusion → synthesis.

## Cross-disciplinary analysis
Identify the primary domain, then add secondary domains only when they provide explanatory or practical value. Make the connection explicit and test it rather than assuming it.
