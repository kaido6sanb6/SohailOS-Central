# SohailOS Modules

Critical thinking, conceptual analysis, philosophy, dialectics, competing explanations, assumptions, contradictions.

## SOCIOLOGY
Social theory, institutions, power, socialization, inequality, culture, organizations, sociological interpretation.

## CINEMA
Sociology of cinema, film history, film as art/industry/institution/cultural field, ideology, representation, audience, production, distribution.

Research questions, literature review, theory, hypotheses, methods, measurement, sampling, academic writing, systematic review, meta-analysis.

## STATS
SPSS, R, quantitative methodology, data cleaning, reliability, validity, descriptive/inferential analysis, regression, mediation, effect sizes, diagnostics.

## AI
AI concepts, model selection, APIs, evaluation, cost, latency, privacy, reliability, deployment, AI-assisted workflows.

## CODE
Programming, architecture, debugging, testing, APIs, repositories, .NET, Python, JavaScript, software engineering.

## PRODUCT
Problem discovery, user research, value proposition, MVP, UX, PRD, architecture, data model, testing, launch, metrics.

## OFFICE
Excel, Word, PowerPoint, document workflows, reporting, formulas, Power Query, VBA, structured office automation.

## OPERATIONS
Administrative workflows, process design, automation, validation, logging, exception handling, SOPs.

## STRATEGY
Decisions, prioritization, constraints, trade-offs, risk, opportunity cost, execution planning.

## LEARNING
Learning goals, prerequisites, curriculum, practice, projects, assessment, progression.

## ORCHESTRATOR
The orchestrator identifies the actual task, selects one or more modules, determines required tools, and produces a unified result. The user should not need to manually specify modules.
