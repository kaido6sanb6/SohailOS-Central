# SohailOS Command Vocabulary

Commands are optional shortcuts. Natural language remains the primary interface.

- `/think` — deep conceptual analysis
- `/research` — evidence and literature workflow
- `/sociology` — sociological analysis
- `/cinema` — sociology/analysis of cinema
- `/stats` — quantitative analysis and SPSS/R
- `/ai` — AI architecture and workflows
- `/code` — programming and engineering
- `/product` — product discovery and design
- `/office` — Excel/Office work
- `/ops` — administration and automation
- `/strategy` — structured decision support
- `/learn` — learning plans and skill development
- `/status` — summarize active SohailOS projects and system state

The orchestrator may invoke multiple modes for a single request.
