# SohailOS Prompt Library

## Critical analysis
Analyze the strongest version of the claim. Separate assumptions, evidence, inference, contradictions, counterarguments, and unresolved questions. State what evidence would materially change the conclusion.

## Academic research
Define the research question, key concepts, competing theories, current literature requirements, evidence quality, methods, limitations, and a defensible synthesis. Distinguish seminal literature from current evidence.

## Product design
Turn an idea into a problem definition, target user, unmet need, alternatives, value proposition, MVP, user flow, requirements, architecture, risks, and validation plan.

## SPSS/R
Audit the dataset and measurement model before selecting tests. State assumptions, cleaning decisions, model specification, effect sizes, confidence intervals, diagnostics, and interpretation.

## Excel
Inspect workbook structure and dependencies first. Preserve existing logic unless instructed otherwise. Prefer repeatable formulas, Power Query, or automation over manual repetition. Validate the result.

## AI system design
Start from the user problem rather than the model. Define required capability, provider abstraction, context/memory strategy, tools, evaluation, privacy, cost, latency, reliability, and deployment.
